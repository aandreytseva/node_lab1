## Установка и запуск

1. Убедитесь, что установлен Node.js (`node -v`) и npm (`npm -v`).
2. Установите зависимости (в проекте они не требуются, но команда стандартна для инициализации):

   ```bash
   npm install
   ```

3. Запустите сервер:

   ```bash
   node app.js
   ```

   или

   ```bash
   npm start
   ```

4. После запуска в терминале появится сообщение:

   ```
   Server is running at http://localhost:3000
   ```

5. Откройте в браузере `http://localhost:3000`.

## Реализованные маршруты

| Метод | URL             | Результат                                              |
|-------|-----------------|---------------------------------------------------------|
| GET   | `/`             | Приветственное сообщение                                 |
| GET   | `/about`        | Информация о приложении / лабораторной работе             |
| GET   | `/student`      | Имя, фамилия и группа студента (текст)                    |
| GET   | `/api/student`  | Данные студента в формате JSON                             |
| GET   | `/time`         | Текущая дата и время сервера                               |
| GET   | `/api/courses`  | Список дисциплин (название, преподаватель, credits) в JSON |
| GET   | `/api/fact`     | Собственный маршрут — случайный факт о Node.js в JSON     |
| любой | всё остальное   | `404 - Page not found` с реальным HTTP-статусом 404       |

## Логирование запросов

Каждый входящий запрос логируется в консоль в формате:

```
HTTP Method | URL | Date and Time
```

Например:

```
GET /about | 09.09.2026 15:25:00
```
